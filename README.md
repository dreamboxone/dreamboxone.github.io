دستی کپی‌پیست کنید.

این ابزار وقتی عالی است که کلی لینک پراکسی و اشتراک نامرتب از چندین ارائه‌دهنده مختلف دارید و می‌خواهید بدون دست‌زدن دستی به YAML، یک کانفیگ یکپارچه و تمیز Clash/Mihomo داشته باشید.

⚠️ این پروژه محصول رسمی تیم‌های Clash/Mihomo نیست و هیچ وابستگی‌ای به MetaCubeX یا نویسندگان دیگر کلاینت‌ها ندارد. فقط با فرمت کانفیگ‌ها و مجموعه‌قوانین آن‌ها کار می‌کند.

این ابزار چه کار می‌کند؟
Mihomo Constructor یک فایل کامل config.yaml برای Clash/Mihomo می‌سازد و این‌ها را با هم ترکیب می‌کند:

لینک‌های پراکسی در فرمت‌های رایج (vless://، vmess://، ss://، trojan://، ssr://، hysteria://، hy://، hy2://، hysteria2://، tuic://)،
اشتراک‌ها (proxy-providers) با امکان انتخاب حالت دریافت،
گروه‌های پراکسی با آیکن، ورودی‌های دستی و پراکسی‌های تولیدشده خودکار،
قوانین ساخته‌شده از لیست‌های GEOSITE / GEOIP، rule-providerها، یا قوانین دستی (DOMAIN/IP/PROCESS)،
بلوک‌های YAML خام برای اشتراک‌ها، گروه‌ها و قوانین، وقتی به کنترل کامل نیاز دارید.
اپ یک صفحهٔ HTML استاتیک با اسکریپت‌های ES module و بدون بک‌اند است: صفحه را باز می‌کنید، ورودی‌ها را می‌چسبانید، تنظیمات را تغییر می‌دهید و YAML آماده را کپی یا دانلود می‌کنید.

نمای کلی قابلیت‌ها
پردازش ورودی‌ها
پارسر ورودی base64 یا متن ساده را نرمال می‌کند و چندین لینک را از یک‌بار پیست‌کردن استخراج می‌کند.
اسکیم‌های پشتیبانی‌شده شامل VLESS، VMess، Shadowsocks، Trojan، ShadowsocksR، Hysteria (نسخه‌های ۱ و ۲)، hy:// و TUIC است؛ بنابراین لیست‌های ناهمگون به‌طور پیش‌فرض کار می‌کنند.
اشتراک‌ها (proxy-providers)
می‌توانید چندین URL اشتراک را یک‌جا اضافه کنید؛ هرکدام خودکار به‌عنوان یک provider ثبت می‌شود.
می‌توانید برای هر اشتراک مشخص کنید که چطور فراخوانی شود (مستقیم – DIRECT یا از طریق Proxy) و یک ناحیهٔ پیشرفتهٔ YAML را فعال کنید تا تعریف provider را دستی جایگزین کنید.
گروه‌های پراکسی
از داخل UI گروه بسازید، نوع آن را انتخاب کنید (select، url-test، fallback، load-balance)، آیکن بگذارید و لیست‌های دستی پراکسی اضافه کنید.
همهٔ پراکسی‌های پارس‌شده با چک‌باکس نمایش داده می‌شوند تا سریع آن‌ها را به گروه‌ها نسبت بدهید؛ حذف یا تغییر نام گروه‌ها، قوانین وابسته را هم به‌روز می‌کند.
یک گروه خودکار به نام auto همهٔ پراکسی‌ها و اشتراک‌های شناسایی‌شده را جمع می‌کند تا قوانین MATCH حتی وقتی گروه‌های دستی خالی باشند، همچنان کار کنند.
قوانین و ترتیب قوانین
دسته‌های GEOSITE/GEOIP را از فایل‌های متنی همراه لود کنید و در آن‌ها جستجو کنید؛ rule-provider اضافه کنید یا قوانین دستی DOMAIN / IP / PROCESS بنویسید.
می‌توانید قوانین را با یک دکمه به‌صورت خودکار گروه‌بندی کنید، هدف پیش‌فرض MATCH (DIRECT/REJECT/یک گروه) را انتخاب کنید و اولویت‌ها را در لیست Rule order جابه‌جا کنید.
برای rule-providerها و خود قوانین، بلوک‌های پیشرفتهٔ YAML وجود دارد تا بتوانید کانفیگ‌های آماده‌تان را مستقیماً وارد کنید.
خروجی و وضعیت
هنگام Build، proxies + groups + providers + rules در یک قطعهٔ YAML ادغام می‌شوند، یک خلاصهٔ وضعیت نمایش داده می‌شود و می‌توانید فوراً config.yaml را کپی یا دانلود کنید.
بومی‌سازی
رابط کاربری با واژه‌نامه‌های انگلیسی، چینی، فارسی و روسی ارائه می‌شود و ترجیح زبان به‌صورت محلی ذخیره می‌شود.
ایموجی‌ها با Twemoji رندر می‌شوند تا آیکن‌ها روی پلتفرم‌های مختلف یکسان‌تر باشند.
چطور از رابط کاربری استفاده کنیم؟
لینک‌ها را پیست کنید داخل باکس “Input links” یا روی Demo بزنید تا نودهای نمونه وارد شوند، بعد روی Build config کلیک کنید.
اشتراک‌ها را اضافه کنید در بخش Subscriptions (proxy-providers)، حالت دریافت را تنظیم کنید و اگر می‌خواهید YAML خام providerها را خودتان بدهید، Advanced Subscriptions (YAML) را باز کنید.
گروه‌های پراکسی را پیکربندی کنید از طریق ➕ Add group؛ نوع، آیکن، پراکسی‌های دستی و این‌که کدام پراکسی‌های پارس‌شده عضو گروه شوند را تعیین کنید. حالت پیشرفته اجازه می‌دهد مستقیم YAML بنویسید.
دادهٔ قوانین را لود کنید با 📄 Load (برای GEOSITE) و 🌍 Load (برای GEOIP)، در دسته‌ها جستجو کنید، rule-provider اضافه کنید یا قوانین دستی وارد کنید. ⚙️ Auto rules group می‌تواند یک‌سری قوانین پیش‌فرض برای شما بسازد و در باکس Rule order می‌توانید اولویت‌ها را تنظیم کنید.
رفتار پیش‌فرض MATCH را تنظیم کنید (DIRECT/REJECT/یک گروه) و اگر لازم بود، YAML پیشرفتهٔ قوانین را ریزتنظیم کنید.
بسازید و خروجی بگیرید: پنل Ready YAML کانفیگ ادغام‌شده را نشان می‌دهد، با دکمه‌های Copy و Download config.yaml. تگ‌های وضعیت تعدادها و خطاهای احتمالی در پارس‌کردن را گزارش می‌کنند.
ساختار مخزن
index.html — رابط تک‌صفحه‌ای که با ماژول‌های سادهٔ JS نوشته شده؛ شامل تمام کنترل‌ها برای ورودی‌ها، اشتراک‌ها، گروه‌ها، قوانین، وضعیت و خروجی YAML است.
styles/ — فونت‌ها و استایل‌های ظاهری رابط.
src/main.js — نقطهٔ ورود که ورودی‌ها را پارس می‌کند، state را بازسازی می‌کند و YAML خروجی را تولید می‌کند.
src/parser.js — پارسر قدرتمند لینک‌های پراکسی که چندین اسکیم و ورودی‌های base64 را مدیریت می‌کند.
src/groups.js — منطق و اتصال‌های UI برای مدیریت گروه‌های پراکسی.
src/subs.js — منطق و اتصال‌های UI برای اشتراک‌ها (proxy-providers).
src/rules.js — مدیریت قوانین، rule-providerها، ترتیب قوانین و رفتار MATCH.
src/geo.js — لود و جستجوی دسته‌های GEOSITE/GEOIP از فایل‌های همراه.
src/yaml-gen.js — مونتاژ YAML نهایی از state اپلیکیشن.
src/i18n.js و src/i18n/ — انتخاب‌کنندهٔ زبان، دیکشنری‌های ترجمه و یکپارچه‌سازی Twemoji.
geo/ — لیست‌های تولیدشدهٔ geosite.txt / geoip.txt برای مرور آفلاین دسته‌های GEOSITE/GEOIP.
geo-update.py — اسکریپت کمکی برای به‌روزرسانی لیست‌های GEO از meta-rules-dat.
اجرای محلی
اپلیکیشن استاتیک است: مخزن را clone کنید و پوشه را با هر سرور استاتیک ساده‌ای سرو کنید تا ES moduleها درست لود شوند، مثلاً:

python -m http.server 8000
بعد در مرورگر به آدرس http://localhost:8000/ بروید. هیچ مرحلهٔ build یا سرویس بک‌اندی لازم نیست.

به‌روزرسانی فایل‌های GEO
فایل‌های geo/geosite.txt و geo/geoip.txt از مخزن MetaCubeX/meta-rules-dat می‌آیند و با اسکریپت geo-update.py دوباره تولید می‌شوند:

python geo-update.py
این اسکریپت مخزن upstream را clone می‌کند، نام دسته‌ها را (با حذف پسوندها) استخراج می‌کند، فایل‌های متنی را به geo/ منتقل می‌کند و clone موقت را پاک می‌کند.

محدودیت‌ها
بدون بک‌اند: اپ کاملاً داخل مرورگر اجرا می‌شود؛ اشتراک‌ها مستقیم از سمت کلاینت دریافت می‌شوند.
فقط مرورگر: هیچ CLI wrapperای وجود ندارد؛ این ابزار روی UI وب تعاملی متمرکز است.
سازگاری کلاینت: خروجی برای کانفیگ‌های سبک Mihomo/Clash.Meta بهینه شده است. بعضی forkها یا کلاینت‌های خیلی سفارشی ممکن است هنوز به اصلاحات دستی نیاز داشته باشند.
بدون تست داخلی نودها: اپ پراکسی‌ها را ping یا benchmark نمی‌کند؛ فقط YAML کانفیگ را تولید می‌کند.
بومی‌سازی و مشارکت
ترجمه‌ها را در src/i18n/*.js اضافه یا اصلاح کنید و localeهای جدید را در src/i18n.js ثبت کنید.
برای تغییرات در پارسر، presetهای جدید یا بهبود UI، آزادانه issue یا PR باز کنید.
لطفاً ترجمه‌های README را در فایل‌های مخصوص خودشان نگه دارید؛ همین نسخهٔ انگلیسی منبع اصلی و مرجع است.
اعتبارها
Mihomo Constructor یک ابزار مستقل کمکی است که بر پایهٔ فرمت‌ها و مجموعه‌قوانین Clash/Mihomo ساخته شده. تمام نام‌های محصولی ذکرشده متعلق به صاحبان آن‌هاست.
